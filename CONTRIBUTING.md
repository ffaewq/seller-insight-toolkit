# Contributing

Thank you for helping make marketplace analysis more transparent.

## Good contributions

- Reproducible rule corrections with an authoritative policy link and access date
- New category profiles with documented field limits and examples
- CSV adapters built from anonymized schemas
- Tests that show false positives or false negatives
- Accessibility, localization, and mobile improvements

## Pull requests

1. Open an issue for material scoring or policy changes.
2. Keep product facts and marketplace rules separate from presentation code.
3. Add a fixture or test for any scoring change.
4. Explain the source, category, marketplace, and effective date of a policy rule.
5. Do not include seller credentials, private reports, customer data, or copyrighted listing datasets.

The project favors explainable heuristics over unexplained AI scores.
