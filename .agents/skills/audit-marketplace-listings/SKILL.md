# Audit Marketplace Listings

1. Establish marketplace, category, verified product facts, field limits, target keywords, and customer scenarios.
2. Run compliance first. Label findings `Blocker`, `Review`, `Opportunity`, or `Pass`; never let SEO offset a blocker.
3. Check field lengths, capitalization, punctuation, unsupported claims, promotions, URLs/contact details, guarantees, medical claims, trademarks, and certification evidence.
4. Map every target keyword across title, bullets, description, and search terms. Do not recommend inaccurate or unnaturally stuffed phrases.
5. Check product definition, package contents, compatibility, specifications, installation, benefits, proof, use cases, objections, differentiation, and limitations.
6. Compare competitors only from sourced data in the same time window. Separate observations from inferences and disclose sample limits.
7. Return a compliance gate, five dimension scores, prioritized findings, keyword coverage table, missing evidence, and specific actions.

Automated checks support but do not replace human policy review.
