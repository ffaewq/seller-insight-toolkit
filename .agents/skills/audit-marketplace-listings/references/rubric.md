# Scoring Rubric

| Dimension | Weight |
| --- | ---: |
| Compliance | 30% |
| Keywords and SEO | 22% |
| Category relevance | 18% |
| Persuasion | 18% |
| Readability | 12% |

A compliance blocker caps the overall score below 70. For persuasion, prefer `customer outcome → mechanism → verifiable proof`. For competitor analysis, report sample size, use medians, keep data dates aligned, label sales estimates, and disclose that the sample may not represent the full market.
