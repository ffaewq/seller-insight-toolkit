# Agent Guide

## Product principles

- Compliance is a gate, not a weighted style preference.
- Do not invent marketplace rules or product facts.
- Keep category limits configurable and sourceable.
- Separate observed competitor data from inferred market conclusions.
- Keep analysis explainable: issue, reason, and action.
- Preserve browser-local processing unless a capability explicitly requires a backend.

## Change checklist

- Run lint and production build.
- Add or update a deterministic fixture for scoring changes.
- Review mobile layout for interface changes.
- Update README and security notes when data access or external integrations change.
